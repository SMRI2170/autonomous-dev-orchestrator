# 安全境界と制約

## 不信なデータと実行権限

Issue本文、リポジトリ内文書、PR本文、レビュー/CIメッセージは不信なデータです。ローカルTOMLだけが対象と権限を決めます。Issueの投稿者が許可リストにあり、指定ラベルがあり、受入条件・依存確認が通った場合のみ処理します。PR本文や一般のIssueコメントからコマンド・許可・マージ判定を取り込みません。

MiniMaxへのデータはJSON境界に入れ、ルールを上書きしないよう明示します。ただし、プロンプトだけでインジェクションを完全に防ぐとは主張しません。モデルにはGitHubトークンやshell toolsを渡さず、任意のCLI引数をモデルから受け付けません。出力を決定的なルールで検査し、検査済みのファイル置換だけをGitHub APIに送ります。提案コード自体が安全であることは静的文字列検査では保証できないため、コードの自動マージをMVPでは禁止しています。

## Macの実行境界

対象コードをcloneせず、git hook、package script、テスト、ビルドをMac上で実行しません。モデル実行は一時ディレクトリ。環境変数はPATH/HOME/TMPDIRと専用MiniMaxプロファイル等に限定。GitHubやOpenAIのAPIキーを継承しません。

Seatbeltはdefault denyで、システム/パッケージランタイムの読取り、専用プロファイルと一時領域の読み書きだけを許可します。ファイルメタデータの取得とrootディレクトリ自体の読取りはNode起動に必要なため許可します。process-execは指定Node実行体だけ。`/bin/sh`等を起動できず、外部ユーザーファイルの読取り・書込みは拒否します。専用profileの認証データはMiniMax自身には見えます。ネットワークはモデル/認証用に許可され、ドメイン制限プロキシは未実装です。したがって、信頼できないCLIバイナリ・独自provider/pluginを登録してはいけません。OSユーザー/VMを分けると境界が強くなります。

SeatbeltはmacOSの既存機能で、長期互換性を保証するものではありません。利用するmacOS/Node/CLIの組み合わせで拒否された場合はBlockedとなります。Sandboxを無効化するfallbackはありません。

## ファイル検査

- 許可glob以外、dotfile、認証/権限/課金/デプロイ/依存設定類、AGENTS等の制御文書、秘密鍵・シェルスクリプトを拒否。
- UTF-8テキストのみ。最大5ファイル・置換後合計50KB（設定で小さくできる）。複数修正の累積集合も検査。
- パストラバーサル、絶対パス、symlink/実行ファイル/submoduleを通る書込みを拒否。
- 代表的なトークン/秘密鍵/認証情報と、危険な実行文字列を拒否。
- gitのモードは100644固定。削除・rename・バイナリ変更を作成しない。

秘密/危険コード検出はパターン方式です。未知の形式や難読化された秘密・危険コードの完全検出は未対応です。CI側にもsecret scanning等を追加できますが、このツールが勝手に導入することはありません。標準ライブラリのみで扱う小さな変更が対象です。

## マージの境界

CodeRabbitの自然言語に「問題なし」とあっても承認ではありません。PR number、head ref、head repo、base repo/ref、head SHAが保存済み意図と一致することを確認します。CIはnameだけでなくapp slugとhead SHAを照合し、同名checkは最新IDを採用します。レビューはlogin・Bot型・commit_id・APPROVEDを照合します。未解決スレッド・古い変更要求・欠けたページ・不明なmergeabilityは合格になりません。

PRの全ファイル名とGit blob SHAを検査します。自動マージ前にレビューを再取得し、strictな保護ブランチ要件を確認します。対象repoの管理者、ローカル設定編集者、OSユーザー、MiniMax配布バイナリは信頼される主体です。

## 状態と運用

SQLiteは`(repo, issue)`一意制約、publish意図と親/commit SHA、修正・呼出し予算を保存します。同じstate_dirに対してflockで1プロセスだけ実行できます。**1台では同じstate_dirを使用してください。** 複数のstate_dirを使った分散ロックは未対応です。

初回+最大3回のモデル呼出し、各モデル実行600秒、レビュー待ち24時間、API45秒、ページ数上限20。期限・権限・CI/モデル/APIの失敗はBlocked。必須CIが未完了/未取得の間は修正回数を消費しません。モデル呼出し直前に予算を永続化し、中断時のリプレイはしません。API側で失われた応答は保存したpublish意図を照合して回復します。

Blockedを自動再試行せず、他のopt-in Issueは次のpollで処理できます。人間のマージ待ちはアクティブ枠を占有し、期限切れでBlockedになります。中断したPRやブランチの自動削除はありません。

## ログ・データ

stateディレクトリ0700、DBとJSONLは0600。CLIのumaskは077です。イベントに本文・プロンプト・モデル出力・HTTP応答・環境変数を記録せず、代表的な秘密パターンをマスクします。HTTP失敗時は応答本文を出しません。SQLiteには検査済み変更内容が復旧目的で残ります。バックアップも同様に非公開で管理してください。

MiniMax Codeが自身のprofile内に作るセッション、監査ログ、テレメトリーは本ツールの管理外です。専用プロファイルの保持方針は利用するCLIで確認してください。モデルに渡す許可ファイルは機密のない公開情報だけに限定します。ログのローテーション・暗号化保存・自動破棄は未実装です。
